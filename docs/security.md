# Security Policy

## Reporting Vulnerabilities

Please do not open public issues for security vulnerabilities.

Report security issues privately by email:

- [open-source@otgh.cloud](mailto:open-source@otgh.cloud)

Include:

- Affected version(s)
- Reproduction steps
- Expected impact
- Proof-of-concept details if available

## Supported Version Line

- 1.x: supported
